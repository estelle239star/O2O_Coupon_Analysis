# O2O 用户消费行为分析与优惠券精准营销策略优化

基于天池 O2O 优惠券消费数据，从用户行为、优惠券属性、消费场景和历史行为等维度进行分析，并结合机器学习模型识别高核销倾向样本，进一步完成精准营销范围优化与营销策略制定。

🔗 **在线 Dashboard：**  
https://o2o-coupon-analysis.streamlit.app/

## 📌 项目概览

优惠券营销中，大范围发券虽然能够提高用户覆盖，但也可能造成大量无效触达。本项目尝试回答两个核心问题：

- 哪些因素会影响用户领取优惠券后的实际核销行为？
- 如何利用历史行为和机器学习模型筛选更值得优先触达的用户？

项目从数据分析出发，经过特征工程和模型构建，最终利用预测概率进行 Top-K 高潜样本筛选，并结合 Lift 和核销用户捕获率评估不同营销范围。

### 核心结果

| 指标 | 结果 |
|---|---:|
| 验证集样本 | 215,348 |
| 实际核销样本 | 21,580 |
| 整体核销率 | 10.02% |
| Top 10% 核销率 | 25.29% |
| Top 10% Lift | 2.52 |
| Top 10% 核销用户捕获率 | 25.23% |

> Top 10% 高潜样本的实际核销率达到 **25.29%**，约为整体核销率 **10.02%** 的 2.52 倍，说明模型排序能够有效识别高核销倾向样本。

## 📊 探索性数据分析

主要从以下维度分析优惠券核销行为：

- 满减门槛与核销表现
- 优惠力度与核销表现
- 用户与商户消费距离
- 用户历史活跃程度
- 用户历史优惠券核销行为

分析结果显示，优惠券核销行为并非仅由优惠力度决定，还与用户历史行为、优惠券属性以及消费场景等因素存在明显关联。

---

## 🛠️ 特征工程

围绕优惠券核销行为构建多维度特征，主要包括：

- **用户行为特征**：历史消费、领券和核销行为
- **商户相关特征**：历史优惠券使用情况等
- **优惠券特征**：折扣率、满减门槛、优惠金额等
- **消费场景特征**：用户与商户距离、领券时间等
- **历史交叉特征**：用户历史优惠券核销情况等

特征构建过程中仅使用预测时点之前能够获得的历史信息，避免未来信息泄漏。

## 🤖 机器学习模型

项目构建并比较三种分类模型：

- Logistic Regression
- Random Forest
- LightGBM

评价指标包括 Accuracy、Precision、Recall、F1 和 ROC-AUC。

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.8975 | 0.4114 | 0.0535 | 0.0946 | 0.6434 |
| Random Forest | 0.4211 | 0.1365 | 0.8970 | 0.2370 | 0.7376 |
| LightGBM | 0.9013 | 0.6024 | 0.0446 | 0.0830 | 0.7165 |

Random Forest 的 ROC-AUC 较高，而 LightGBM 在 Accuracy 和 Precision 上表现较好。

考虑到后续任务重点是根据预测概率进行高潜样本排序，项目进一步使用 LightGBM 输出的核销概率进行 Top-K 精准营销分析。

## 🎯 精准营销分析

验证集整体优惠券核销率为 **10.02%**。

按照模型预测核销概率从高到低排序：

| 营销范围 | 实际核销率 | Lift | 核销用户捕获率 |
|---|---:|---:|---:|
| Top 10% | 25.29% | 2.52 | 25.23% |
| Top 20% | 20.67% | 2.06 | 41.25% |
| Top 30% | 18.50% | 1.85 | 55.39% |

可以看到，随着营销范围扩大，能够覆盖更多实际核销用户，但单位触达效率逐渐下降。

因此：

- **预算有限：** 优先触达 Top 10% 高潜样本
- **兼顾效率与覆盖：** 可将 Top 20% 作为重点营销范围
- **扩大用户覆盖：** 可进一步扩大至 Top 30%，但需要接受核销效率下降

## 💡 营销策略

### 1. 高潜用户优先触达

根据模型预测概率对样本进行排序，将有限营销资源优先投入高核销倾向人群。

### 2. 优惠券差异化设计

综合考虑优惠力度和满减门槛，避免单纯依靠提高优惠力度获取转化，并根据不同用户行为制定差异化优惠方案。

### 3. 消费场景优化

结合用户与商户距离等场景信息，在相同预测水平下优先覆盖消费便利性较高的用户。

### 4. 用户分层运营

- 高价值用户：重点维护并优先触达
- 普通活跃用户：采用适度优惠促进转化
- 无历史行为用户：采用较低成本优惠进行试探性触达
