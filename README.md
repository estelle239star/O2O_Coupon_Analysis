# O2O用户消费行为分析与优惠券精准营销策略优化

## 项目简介

本项目基于天池 O2O 优惠券消费数据，从用户行为、优惠券属性、消费场景和历史行为等维度进行数据分析，并构建机器学习模型预测用户优惠券核销倾向。在此基础上，通过高潜样本识别、Top-K 营销分析、Lift 与核销用户捕获率等指标评估不同营销范围，最终形成差异化精准营销策略。

同时使用 Streamlit 构建可视化 Dashboard，对项目核心分析结果进行展示。

## 项目流程

数据清洗与标签构建  
→ 探索性数据分析  
→ 用户与商户历史特征构建  
→ 优惠券与消费场景特征构建  
→ Logistic Regression / Random Forest / LightGBM  
→ 模型效果评估  
→ 高潜用户识别  
→ Top-K 精准营销分析  
→ 营销策略制定  
→ Streamlit Dashboard

## 数据分析

主要从以下几个方面分析优惠券核销行为：

- 满减门槛与核销表现
- 优惠力度与核销表现
- 用户与商户消费距离
- 用户历史活跃程度
- 用户历史优惠券核销行为

分析结果表明，优惠券核销行为并非仅由折扣力度决定，还与用户历史行为、商户特征及消费场景等因素存在明显关联。

## 机器学习模型

项目构建并比较了三种分类模型：

- Logistic Regression
- Random Forest
- LightGBM

模型主要评价指标包括：

- Accuracy
- Precision
- Recall
- F1
- ROC-AUC

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---:|---:|---:|---:|---:|
| Logistic Regression | 0.8975 | 0.4114 | 0.0535 | 0.0946 | 0.6434 |
| Random Forest | 0.4211 | 0.1365 | 0.8970 | 0.2370 | 0.7376 |
| LightGBM | 0.9013 | 0.6024 | 0.0446 | 0.0830 | 0.7165 |

Random Forest 的 ROC-AUC 较高，而 LightGBM 在 Accuracy 和 Precision 上表现较好。后续高潜样本识别、Top-K 营销分析和特征重要性分析主要基于 LightGBM 的核销概率输出完成。

## 精准营销分析

验证集整体优惠券核销率为 **10.02%**。

按照模型预测核销概率对用户进行排序后：

| 营销范围 | 实际核销率 | Lift | 核销用户捕获率 |
|---|---:|---:|---:|
| Top 10% | 25.29% | 2.52 | 25.23% |
| Top 20% | 20.67% | 2.06 | 41.25% |
| Top 30% | 18.50% | 1.85 | 55.39% |

结果表明，模型能够有效识别高核销倾向样本。

当营销预算有限时，可优先触达 Top 10% 高潜样本；当需要兼顾营销效率与用户覆盖时，可将 Top 20% 作为重点营销范围。

## 营销策略

根据数据分析与模型结果，形成以下策略：

1. **用户筛选**
   - 预算有限时优先触达 Top 10% 高潜用户
   - 兼顾效率与覆盖时采用 Top 20%
   - 对具有多次历史核销记录的用户重点维护

2. **优惠券设计**
   - 综合考虑折扣力度和满减门槛
   - 避免单纯通过增加折扣提高吸引力
   - 根据不同用户行为设计差异化优惠

3. **场景化营销**
   - 优先覆盖距离较近的高潜用户
   - 结合模型预测概率确定触达优先级

4. **用户差异化运营**
   - 高价值用户：重点维护并优先触达
   - 普通活跃用户：使用适度优惠促进转化
   - 无历史行为用户：采用低成本优惠进行试探性触达
